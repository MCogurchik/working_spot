# Zombie Tower Defense - Roblox Studio

## Описание игры
Это полноценный режим Tower Defense для Roblox Studio, где игроки должны защищать свою базу от волн зомби. Игроки зарабатывают монеты за убийство зомби и могут тратить их на покупку нового оружия или улучшение существующего.

## Особенности
- 🧟 Система волн зомби с увеличивающейся сложностью
- 💰 Экономическая система с монетами
- 🔫 Разнообразное оружие с системой улучшений
- 🏰 Система защиты базы с HP
- 📊 Интуитивный пользовательский интерфейс
- ⚡ Автоматический спавн и ИИ зомби
- 🎯 Автоматическое нацеливание на ближайших врагов
- 📈 Система уровней и опыта
- 🛒 Интерактивный магазин оружия
- 🎨 Красивые визуальные эффекты

## Подробная инструкция по установке

### Шаг 1: Подготовка Roblox Studio
1. Откройте **Roblox Studio**
2. Создайте новое место (Place) или откройте существующее
3. Убедитесь, что у вас есть права на редактирование
4. Сохраните место перед началом установки

### Шаг 2: Создание структуры папок в Explorer
1. В **Explorer** (левая панель) найдите следующие службы:
   - **ServerScriptService** (если нет, создайте)
   - **StarterPlayerScripts** (если нет, создайте через StarterPlayer)
   - **StarterGui**
   - **ReplicatedStorage**

2. В **ReplicatedStorage** создайте папку **"Modules"**:
   - Правый клик на ReplicatedStorage → Insert Object → Folder
   - Переименуйте в "Modules"

### Шаг 3: Установка серверных скриптов
1. В **ServerScriptService** создайте следующие скрипты:

   **GameManager** (ServerScript):
   - Правый клик на ServerScriptService → Insert Object → Script
   - Переименуйте в "GameManager"
   - Скопируйте код из `src/ServerScriptService/GameManager.lua`

   **ZombieController** (ServerScript):
   - Создайте новый Script, переименуйте в "ZombieController"
   - Скопируйте код из `src/ServerScriptService/ZombieController.lua`

   **EconomyManager** (ServerScript):
   - Создайте новый Script, переименуйте в "EconomyManager"
   - Скопируйте код из `src/ServerScriptService/EconomyManager.lua`

   **WeaponController** (ServerScript):
   - Создайте новый Script, переименуйте в "WeaponController"
   - Скопируйте код из `src/ServerScriptService/WeaponController.lua`

### Шаг 4: Установка клиентских скриптов
1. В **StarterPlayerScripts** создайте:

   **ClientGameManager** (LocalScript):
   - Правый клик на StarterPlayerScripts → Insert Object → LocalScript
   - Переименуйте в "ClientGameManager"
   - Скопируйте код из `src/StarterPlayerScripts/ClientGameManager.lua`

2. В **StarterGui** создайте:

   **GameUI** (LocalScript):
   - Правый клик на StarterGui → Insert Object → LocalScript
   - Переименуйте в "GameUI"
   - Скопируйте код из `src/StarterGui/GameUI.lua`

### Шаг 5: Установка модулей
1. В **ReplicatedStorage** создайте:

   **RemoteEvents** (ModuleScript):
   - Правый клик на ReplicatedStorage → Insert Object → ModuleScript
   - Переименуйте в "RemoteEvents"
   - Скопируйте код из `src/ReplicatedStorage/RemoteEvents.lua`

   **GameData** (ModuleScript):
   - Создайте новый ModuleScript, переименуйте в "GameData"
   - Скопируйте код из `src/ReplicatedStorage/GameData.lua`

2. В **ReplicatedStorage/Modules** создайте:

   **ZombieData** (ModuleScript):
   - Правый клик на папку Modules → Insert Object → ModuleScript
   - Переименуйте в "ZombieData"
   - Скопируйте код из `src/ReplicatedStorage/Modules/ZombieData.lua`

   **WeaponData** (ModuleScript):
   - Создайте новый ModuleScript, переименуйте в "WeaponData"
   - Скопируйте код из `src/ReplicatedStorage/Modules/WeaponData.lua`

   **Utilities** (ModuleScript):
   - Создайте новый ModuleScript, переименуйте в "Utilities"
   - Скопируйте код из `src/ReplicatedStorage/Modules/Utilities.lua`

### Шаг 6: Настройка карты
1. **Создайте базу игроков**:
   - Создайте Part в workspace
   - Переименуйте в "PlayerBase"
   - Установите размер примерно 10x10x10
   - Покрасьте в зеленый цвет

2. **Создайте точки спавна зомби**:
   - Создайте несколько Part'ов вокруг карты
   - Переименуйте их в "ZombieSpawn1", "ZombieSpawn2", "ZombieSpawn3", "ZombieSpawn4"
   - Разместите на расстоянии 50-100 studs от базы
   - Покрасьте в красный цвет

3. **Настройте спавн игроков**:
   - Убедитесь, что SpawnLocation находится рядом с базой
   - Если нет, создайте новый SpawnLocation

4. **Добавьте препятствия** (опционально):
   - Создайте стены, здания для более интересного геймплея
   - Зомби будут использовать Pathfinding для обхода препятствий

### Шаг 7: Тестирование
1. **Сохраните место** (Ctrl+S)
2. **Нажмите Play** для тестирования в студии
3. **Проверьте Output** на наличие ошибок
4. **Протестируйте основные функции**:
   - Спавн зомби
   - Стрельба (клавиша F)
   - Перезарядка (клавиша R)
   - Магазин (клавиша Tab)
   - Смена оружия (клавиши 1-5)

### Шаг 8: Публикация (опционально)
1. **File → Publish to Roblox As...**
2. Дайте игре название и описание
3. Настройте доступ (Private/Friends Only/Public)
4. Нажмите **Create**

## Управление игрой
- **F** - Стрелять (автоматическое нацеливание на ближайшего зомби)
- **R** - Перезарядка
- **Tab** - Открыть/закрыть магазин оружия
- **1-5** - Быстрое переключение оружия
- **Escape** - Закрыть магазин

## Доступное оружие
1. **Glock 17** (Стартовое) - Надежный пистолет
2. **Дробовик** (Ур. 2) - Мощное оружие ближнего боя
3. **Desert Eagle** (Ур. 3) - Пистолет с высоким уроном
4. **AK-47** (Ур. 4) - Автоматическая винтовка
5. **M4A1** (Ур. 5) - Точная штурмовая винтовка
6. **Двустволка** (Ур. 6) - Разрушительная двустволка
7. **AWP** (Ур. 8) - Мощная снайперская винтовка
8. **Миниган** (Ур. 9) - Скорострельное оружие
9. **Гранатомёт** (Ур. 10) - Взрывное оружие

## Типы зомби
- **Обычный зомби** - Медленный, но живучий
- **Быстрый зомби** (с 3 волны) - Быстрый, но слабый
- **Зомби-танк** (с 5 волны) - Очень медленный, но невероятно живучий
- **Зомби-босс** (с 10 волны) - Мощный босс на волнах-боссах

## Система прогрессии
- Убивайте зомби для получения **опыта** и **монет**
- Повышайте **уровень** для разблокировки нового оружия
- Покупайте новое оружие или **улучшайте** существующее
- Каждые 5 волн - **волна боссов** с особыми наградами

## Решение проблем

### Зомби не спавнятся
- Проверьте наличие объектов "ZombieSpawn1", "ZombieSpawn2" и т.д. в workspace
- Убедитесь, что GameManager и ZombieController правильно установлены
- Проверьте Output на ошибки

### UI не отображается
- Убедитесь, что GameUI в StarterGui имеет тип **LocalScript**
- Проверьте, что все модули правильно установлены в ReplicatedStorage
- Убедитесь, что нет ошибок в Output

### Оружие не работает
- Проверьте настройки RemoteEvents в ReplicatedStorage
- Убедитесь, что ClientGameManager правильно установлен
- Проверьте соединение между клиентом и сервером

### Ошибки в Output
- **"Module not found"** - Проверьте, что все модули установлены в правильные папки
- **"Remote event not found"** - Убедитесь, что RemoteEvents.lua правильно установлен
- **"Unable to cast"** - Проверьте типы скриптов (Script vs LocalScript vs ModuleScript)
